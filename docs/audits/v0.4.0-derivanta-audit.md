## 2. Cobertura de inspeção

- Universo: 348 arquivos versionados; `.kilo/worktrees` (cópia de outra ferramenta, não versionada) excluída.
- Lido integralmente: navegação, draft coordinator, manifest/XML, repositórios (scan, processamento, OCR, export, preferências), entidades/mappers Room, telas Home/Editor/OCR/Export/Histórico/Settings, componentes de UI, workflows, gates Python, docs canônicos.
- Lido por amostragem: catálogos de strings (termos-chave), `OcrTextPostProcessor`, `ScanFileStore`, `QuadEditorOverlay`, site.
- Executado: build debug de baseline; log do job API 36 falho (uma leitura).
- Não exercitado: câmera física, TalkBack, fonte 200%, RTL em aparelho, corpus físico. Esses pontos permanecem **não validados**.
