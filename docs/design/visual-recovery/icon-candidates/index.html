Ícones em avaliação

Quatro alternativas inspiradas na raposa aprovada, com exatamente duas patas dianteiras visíveis. A opção 4 responde ao pedido de uma composição entre 2 e 3 com sinal de escaneamento. As capturas vieram do emulador Android API 34. A primeira linha de cada prancha usa AdaptiveIconDrawable e a máscara real do sistema em 24, 48, 72 e 108 dp. As outras máscaras são prévias desenhadas no Android. O ícone temático é um rascunho vetorial separado. Nenhuma alternativa está instalada no launcher ou aprovada para release.
