# Candidatos da raposa — revisão, não assets de runtime

`original-v0.4.0.png` é uma cópia exata de
`core-ui/src/main/res/drawable-nodpi/replicascan_mascot_welcome.png` na tag
`v0.4.0`; serve para comparação de identidade, não representa aprovação nova.
`master-v1.png` foi editado com imagegen a partir desse original e recebeu
aceite expresso do proprietário como **estilo** em 2026-10-12. As seis poses
`*-v1.png` foram geradas a partir do master e das poses históricas correspondentes.
Estão em revisão; a aprovação do estilo não aprova automaticamente poses,
movimento, telas ou release.

Abrir [review.html](review.html) para comparar as sete poses e o original lado
a lado. O HTML apenas apresenta os PNGs; nenhuma arte dos ZIPs Lume/Pipa foi
incorporada. Os prompts de geração especificaram a mesma identidade, corpo
compacto, bandana turquesa, cauda com ponta branca e props abaixo do rosto.
Esta pasta é evidência de decisão; integrar no app somente após aceite das
poses e validação nativa de animação e desempenho.
