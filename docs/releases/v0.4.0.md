# ReplicaScan v0.4.0

First public release under the ReplicaScan name. Scanning now runs on Google's on-device document scanner, and ReplicaScan focuses on what it owns: private storage, review, text recognition, search and export.

## Highlights

- **Scan uses ML Kit Document Scanner.** Edge detection, perspective, cleanup and multi-page capture happen on the device. You no longer pick a document type first.
- **Fallback without Google Play services:** take a photo with the system camera or import images, then adjust the corners by hand.
- **Removed:** the in-house edge detector, live camera analyzer, CameraX, document modes and the app's own CAMERA permission.
- **Review is document-first** with labeled Crop, Rotate, Adjust and Text tools, confirmation before deleting, and a side panel on wide screens.
- **Four page looks:** Original, Enhanced, Grayscale, Black & white.
- **Text recognition:** one recognizer picked from the app language (Latin, Devanagari, Japanese, Korean), stored text is reused, and another language can be tried. Arabic text recognition is not available in ML Kit and is not claimed.
- **Export:** PNG no longer passes through a lossy JPEG, untouched JPEG pages are copied as-is, and a failed export leaves no partial files.
- **12 languages** rewritten with one consistent glossary; RTL crop handles fixed.
- **Engineering:** about 1,300 lines of unreachable detection code removed, 0 Kotlin warnings, deprecated APIs migrated, API 36 instrumentation moved to Gradle Managed Devices with KVM, release identity derived from `release/manifest.json`.

## Evaluation build

`replicascan-v0.4.0-debug.apk` is an **evaluation (debug-signed) APK**, not a Play Store build. Check it against `SHA256SUMS.txt`; `build-metadata.json` records the source commit.

The package `com.soturine.replicascan` installs separately from builds published under the previous name. Export anything important from the old installation before removing it.

## Privacy

Documents stay on the device and the ReplicaScan code makes no network calls. The scanner and text recognition are delivered and updated by Google Play services, which may download components and report technical metrics under Google's terms. See `PRIVACY_POLICY.md`.

## Known limitations

- Scanning requires Google Play services and at least 1.7 GB of RAM; otherwise use photo + manual crop.
- The searchable PDF text layer is not positioned word by word yet.
- Not yet validated on physical devices: scanner and fallback, document/OCR corpus, TalkBack, 200% font, RTL, tablets.
- Translations have not been reviewed by native speakers.
