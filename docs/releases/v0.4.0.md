# ReplicaScan v0.4.0

ReplicaScan v0.4.0 establishes the current product, Android and repository identity and adds a fail-closed engineering/release foundation without redesigning the stable document workflow.

## Highlights

- Complete current-surface rebrand to ReplicaScan.
- New Android application ID `com.soturine.replicascan` and version code 19.
- Proprietary current-code license with preserved historical Apache 2.0 boundary.
- Branding, localization, consistency, package and FileProvider regression gates.
- API 36 release instrumentation, CodeQL and exact-artifact publication with SHA-256 and provenance attestation.

## Evaluation build

The attached `replicascan-v0.4.0-debug.apk` is an evaluation/debug APK. It is not production-signed and is not a Play Store AAB.

The new package installs separately from historical builds. Export anything important from the previous installation before removing it. ReplicaScan does not migrate or delete the old app or its external export directory.

Physical camera, crop corpus, TalkBack, 200% font, RTL and representative-device validation remain owner QA and are not implied by automated gates.
