# Scanora v0.3.1 — matriz de implementação e auditoria

Esta página é o controle curto e verificável da v0.3.1. Ela traduz o prompt de produto em entregas com evidência concreta e evita que requisitos fiquem implícitos. O status só muda para **CONCLUÍDO** quando há implementação e validação correspondente.

Status usados: **CONCLUÍDO**, **PARCIAL**, **A FAZER**, **REGRESSÃO**, **N/A** e **ADIADO** (sempre com motivo).

## Checklist de atualização desta matriz

- Atualizar o estado junto com cada commit funcional, citando teste ou arquivo principal.
- Se algo não puder entrar na v0.3.1, marcar **ADIADO** com causa e impacto — nunca omitir.
- Antes da tag, não pode haver **REGRESSÃO** nem item P0 em **A FAZER** sem decisão explícita no changelog/roadmap.
